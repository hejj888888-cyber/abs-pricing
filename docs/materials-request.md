## 6. 物料 5｜第三单产品（第 7 周才用，现在不用急）

### 6.1 要什么样的

现在两单结构高度相似（都是循环购买 + 三档/四档顺序偿付 + 次级期间收益封顶）。第三单需要**结构上有明显差异**，才能证明模型有泛化性，而不是只会算一个模子。

### 6.2 三个候选方向（选一个即可）

| 方向 | 差异点 | 为什么有价值 |
|---|---|---|
| **A. 交易所市场消费金融 ABS**（如京东白条、蚂蚁花呗系列） | 有差额支付承诺、循环购买、储备账户 | 与银行间市场结构不同，能测"外部增信"对票面的影响 |
| **B. 汽车贷款 ABS** | 资产久期长（3–5 年）、提前还款率高、无循环购买 | 完全不同的资产类型，能测模型对长久期资产的适应性 |
| **C. 信用卡分期 ABS** | 循环购买 + 更短久期 + 高周转 | 与消费贷最接近但有区分度 |

**推荐 A**：结构差异最大，且同样在消费金融范畴内，GAP 分析时容易对照。

### 6.3 要什么
