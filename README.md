# 消费金融 ABS 分层定价工具

《投资银行理论与实践》期末作业 · 选题一

用纯 Python 标准库实现消费金融 ABS 的完整定价链路：**资产池 → 逐月现金流（含循环购买） → 分层瀑布 → 票面反解 → 压力测试 → 分层厚度反解**。

本项目的重点不是"算出一个价格"，而是回答一个具体的差距问题：**我的定价流程和行业头部的定价流程，差在哪一步。**

---

## 一、当前版本（第 1 周完成）

两只有公开披露的消费金融 ABS，参数全部换成**评级报告披露的真实值**：

| 案例 | 发起机构 | 规模 | 收益率 | 核销率 | 月还款率 | 分层 |
|---|---|---|---|---|---|---|
| 鼎柚2025年第三期 | 中原消金 | 15.03 亿 | 21.15% | 3.14% | 19.87% | A/B/C/次级 = 74.4/5.8/10.3/9.2 |
| 够花2025年第二期 | 海尔消金 | 15.00 亿 | 23.57% | 4.41% | 16.23% | A/B/次级 = 71.2/8.3/20.5 |

### 三个结论

**第一，票面能对上市场。** 海尔这单的实际发行票面是 A 档 1.80%、B 档 1.95%；在同样的资产池参数和同样的分层下，本模型反解出 A 档 1.79%、B 档 1.93%——**差 1 个和 2 个基点**。这是"算得对"最硬的证据。

**第二，分层厚度不是由"不违约"决定的。** 反解"压力情景下优先档不违约"所需的最小次级厚度，两单分别只要 0.5% 和 1.0%；而市场实际做到 9.2% 和 20.5%，相当于基准情景净损失的 **3.6 倍和 5.3 倍**。中间这段差额是评级机构的缓冲要求（模型误差、参数漂移、资产置换质量下降），披露文件里看不到，也正好是本模型反解不出来的部分。

**第三，超额利差是消费金融 ABS 的命门。** 资产端 21–24%、证券端 1.8–3.5%，超额利差高达 13–21%/年。它比次级档厚度更能吸收损失——极端情景下次级厚度已经被穿透 0.26 个百分点，但次级实际只亏 2.35%，因为利差先把损失吃掉了。**忽略这一层会算出离谱的结果**（第一版没有约束次级期间收益，次级收益率算到 89%）。

## 二、怎么跑

零依赖，只需要 Python 3.8+。

```bash
python scripts/run_case.py --all        # 跑全部案例 + 横向对比
python scripts/run_case.py              # 只跑鼎柚
python scripts/run_case.py --case cases/gouhua_2025_2.json
python -m unittest discover -s tests -v # 14 项冒烟测试
```

产出：

- `output/<case>_report.md`：完整定价报告（八个部分，含参数来源表）
- `output/<case>_schedule.csv`：逐月现金流明细，可直接导入 Excel 复核

## 三、模型结构

```
abs/pool.py       资产池：评级机构四参数口径（收益率/核销率/月还款率/购买率）
abs/cashflow.py   现金流：循环购买期（本金再投资、余额不变）+ 摊还期（按月还款率摊还）
abs/waterfall.py  瀑布：服务费→各档利息→各档本金→次级期间收益封顶→超额留存期末释放
abs/pricing.py    定价：反解票面、IRR、WAL、本金损失率
abs/structure.py  结构：反解"优先档不违约"所需的最薄次级厚度
```

### 两个关键设计

**参数口径换成评级机构的。** 第一版用教科书的"等额本息 + CPR/CDR"，后来发现评级报告披露的是"收益率/核销率/月还款率/购买率"四个参数。口径不同，算出来的厚度根本没得比——比的是口径差异，不是能力差异。所以第 1 周就把参数体系换成对方的口径。

**票面是反解的。** 教科书写"给定票面算价格"，但分层设计的实际提问是"这一档要按面值卖给投资者，票面得给到多少"。`solve_coupons()` 用二分法：调票面 → 重跑瀑布 → 看 IRR 是否命中目标 → 收敛。

## 四、验证

```bash
python -m unittest discover -s tests -v
```

14 项测试覆盖四类易错点：

| 类型 | 检查什么 |
|---|---|
| 口径换算 | 年化核销率 → 月度核销率的折算是否自洽 |
| 现金流 | 循环期余额是否维持不变；摊还期余额是否单调下降至零 |
| 守恒 | 池收回总额 = 服务费 + 各档分得现金流（每次运行强制校验，残差 0.00 元） |
| 收敛与单调 | 票面反解是否命中目标收益率；次级越厚，优先档损失不得变大 |

## 五、参数来源与假设

| 类别 | 鼎柚2025三期 | 够花2025二期 |
|---|---|---|
| 披露参数（直接引用） | 收益率、核销率、月还款率、购买率、资产池余额、分层占比、**持续购买期 8 个月**、**回收率 3.31%**、**回收周期 6 个月** | 同左，另含 A/B 档实际票面；**持续购买期 6 个月**、**回收率 2.78%**、**回收周期 6 个月** |
| 假设参数（仍未取到） | 服务费率 0.5%/年、摊还期上限 12 个月 | 同左 |

- 量化参数来源：联合资信信用评级报告（链接见各 `cases/*.json` 的 `source` 字段）。
- **回收率与回收周期**来自中债资信评级报告《表15：压力测试的基准条件和加压幅度》基准条件；原件使用「回收周期（月）」而非「回收滞后」，本模型按回收周期理解并映射到 `recovery_lag_months`。
- **持续购买期**来自发行说明书。原件用「持续购买」而非教科书的「循环购买」，本模型沿用「循环购买」这一通用术语，但数据取自「持续购买」条款。
- 完整校准过程与影响量化见 `docs/param-calibration.md`。
- **每个参数在报告第一节都标了是"披露"还是"假设"**，假设项在第八节逐条说明影响。

## 六、已知局限

1. 循环期内假设购买率 100%、资产池余额严格不变，未刻画资产置换质量下降与合格资产不足。
2. 真实交易在循环期按季付息，本模型按月计息并当月支付，会小幅高估优先档现金流的时间价值。
3. 核销率仍为全周期恒定值，未按账龄刻画（爬坡—平台—衰减）。评级报告只提供静态池累计违约率**曲线图**，未提供可机读的逐期表格，故第 2 周改用图像读数或行业经验曲线标定。
4. 未建模混同风险、服务机构替换、外部增信（差额支付承诺等）。
5. **拿不到逐笔静态池数据**——这是结构性缺口，不是能力问题，详见 `docs/gap-analysis.md`。
