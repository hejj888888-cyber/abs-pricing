# 案例参数登记表

## 当前状态

| 案例文件 | 数据状态 | 说明 |
|---|---|---|
| `consumer_abs_base.json` | **合成基准参数** | 参数取自行业常见区间，用于跑通引擎与校验逻辑；**尚未替换为真实产品数据** |

> 合成参数不是"随便编的"：加权平均利率 18%、CDR 6%、CPR 15%、回收率 25%、服务费 1.5% 均落在消费金融 ABS 的常见披露区间内，目的是让引擎结果在量级上站得住。但**量级合理不等于事实准确**，正式交付前必须替换。

## 第 1 周任务：替换为真实产品参数

选 2–3 只**公开披露充分**的消费金融 ABS，逐项抄录并登记来源。推荐优先级：

1. 交易所市场的消费金融 ABS：发行说明书通常披露资产池的加权平均利率、账龄、剩余期限、借款人集中度
2. 银行间市场的个人消费贷款 ABS：信息披露更完整，含分层结构与各档利率
3. 绿色信贷 ABS / 绿色 ABN：作为第二类案例，用于对比不同基础资产的参数差异

### 填写纪律

- **每个数字都要能指回披露文件的具体位置**（页码或章节），抄不到就留空，不许用行业均值顶上还标注成"披露值"。
- 披露口径不一致时（例如一个用年化 CPR、一个用累计早偿率），**在备注里写清换算方式**，不要静默转换。
- 替换完成后，本文件必须同步更新"当前状态"表，把数据状态改为"真实披露参数"。
