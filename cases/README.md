## 未披露、由我假设的参数

| 参数 | 取值 | 为什么这样假设 |
|---|---|---|
| 核销后回收率 | 10% | 消费贷核销时点通常已逾期 180 天以上，后续回收率低；10% 属保守取值 |
| 回收滞后 | 6 个月 | 与核销后委外催收的常见周期一致 |
| 服务费率 | 0.5%/年 | 评级报告未单列；参考同类交易贷款服务机构报酬区间 |
| 循环购买期 | 6 个月 | 按优先A 档预期到期日（发行后约 12–13 个月）倒推 |
| 摊还期上限 | 12 个月 | 同上 |

**这些假设要单独标注，不能混进披露值里。** 报告第一节的"来源"列已逐项区分。

## 第三单候选（待补）

若要再补一单做第三方对照，优先选**结构不同**的产品，而不是同质的第三只：

- 绿色信贷 ABS / 绿色 ABN：基础资产为对公贷款，期限长、早偿率低、分层薄，与消费贷形成对照
- 汽车抵押贷款 ABS：有抵押物，回收率高，触发机制不同
